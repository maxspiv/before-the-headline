    04 Technical results — separate historical multilingual experiment Optional · separate from every investigation above · feasibility, not validated detection

    A bounded check of whether GDELT's separate translated GKG stream carries usable historical source-language labels. It is independent of every investigation on this page and did not build or evaluate a detector.

    6translated GKG files verified
    14,725GKG records
    60reported source-language code values
    14,320distinct typed document identifiers
    6non-English article bodies confirmed by manual review

    What was established

    Six translated GKG ZIPs for 00:00 and 00:15 UTC on 1 March 2015, 2017 and 2019 returned HTTP 200 and matched manifest sizes and MD5s. Every record carried an explicit srclc source-language code and a translated-record marker. Codes are retained as supplied; 60 code values are not a validated census of 60 languages.

    Article-body language check

    A frozen, topic-independent sample of 96 URLs (72 native, 24 translated) was fetched with caching and robots checks. 49 returned HTTP success; 35 diagnostic body-language candidates remained after review. Manual inspection supported six substantial non-English bodies: Russian, Arabic, Finnish, Ukrainian, Spanish and French. Current pages are not guaranteed to match 2015–2019 text.

    What is not established

    The native GKG sample (15,339 records) had every language field blank; blank is unknown, not English, so a comparable English denominator remains unvalidated. No 28-day corpus was downloaded (the listed compressed GKG window exceeds 50 GB). No detector, alert threshold, lead time or held-out false-alarm rate was evaluated — these are not evaluated, not zero.

    Details, evidence paths and the recommended next experiment: HISTORICAL_FEASIBILITY.md in the repository. The raw historical caches are not part of this checkout.
