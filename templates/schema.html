Investigation import schema (version 1)

A JSON object describing a self-contained investigation. Download a working example from the template endpoint.

Top-level fields

schema_version (required, must equal 1); id (required slug, ^[a-z0-9][a-z0-9_-]{2,63}$); title, topic (required); optional description, story_label, coverage_status, aggregate_context, uncertainties, timeline_notes.

articles (required, 1–500)

Each article needs id, title, publisher, language (lowercase, e.g. "english") and relevance (related | unrelated | uncertain). Optional: url (http/https only), origin_label, inspected, duplicate_group, duplicate_status, claimed_timestamp ({value, precision: date|datetime}), publisher_visible_timestamp, excerpt, scope_notes, syndication_assessment, reported_event_timestamps_and_uncertainty, include_in_replay.

Validation

Unknown fields are rejected. All validation errors are collected and returned together as {errors: [...]} with per-field paths. Requests are limited to 1 MiB.
